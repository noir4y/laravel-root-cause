# v0.2.0

## Breaking

- Collection now defaults to `enabled` only when `APP_ENV=local`.
- Staging, production, and other non-local environments must opt in with `ROOT_CAUSE_ENABLED=true` to keep writing traces.

## Added

- Reworked public positioning to explain the package against Telescope, Debugbar, and Ray.
- Added quickstart and production safety docs.
- Added release notes, contributor guidance, security policy, and changelog.
- Added retention management with `root-cause:prune` and `ROOT_CAUSE_RETENTION_DAYS`.
- Added structured examples for validation failures, exceptions, and query pathologies.
- Added links to demo app and screenshot assets for terminal and JSON output.

## Fixed

- Aligned the README installation snippet with the package name published on Composer.
- Clarified what the package does and does not do before install time.
- Documented redaction and retention behavior instead of leaving them implicit.

## Known limitations

- The package remains focused on request-scoped diagnosis and JSON export.
- GitHub release publication and repository metadata updates still need to be pushed from the hosting side.
